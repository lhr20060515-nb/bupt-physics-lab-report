# 共用方法：保留依据，控制正文

具体阶段、栏目和小项按 [报告本结构](report-form.md)；物理模型按相应实验分流。以下是执行规则，不是额外的报告正文栏目。

## 实验前与计算前

1. 对照当次讲义与记录，确认要测的量、必做/选做、装置、计数约定和原题；未知项只在影响处理时询问。预习写计划，实验后依据记录写已完成内容。
2. 保留原始读数、编号、签认和修正痕迹。区分分辨率、量程、最大允许误差；单次量与重复量分别识别。不能为接近参考值调整数据；有疑点先查原件。
3. 先核对能改变结果的输入：净质量/总质量、平台/夹具是否随动、实际测量区间及附件参数组别。必要假设与缺口集中一处说明，不把假设写成已核实仪器参数。

## 数据计算、不确定度、结果讨论

1. 先分别完成全部方法的均值、换算、标定和目标量计算；保留输入到结果的对应。只生成本任务有用的图表，图形与列式规则见 [计算与图表](data-presentation.md)。
2. 然后分别评定所需不确定度。按 [第一节课约定](measurement-basics.md) 选用整套口径：课堂默认uA=t·s/√n、uB=适用仪器误差限；六次测量的uA≈s仅为指定近似。明确要求一般标准不确定度时再统一切换，不能叠加两套系数。
3. 同一输入在公式多处出现时先合并敏感系数；共享周期、波长、标尺等须考虑相关性。不能把标定量与其原始输入再当独立量重复传播。正文给本模型简化式、必要代入和结果；完整推导只在题目要求时展开。
4. 最后按课堂修约规则写数值、±及其定义、单位、相对不确定度，再比较其他方法或适用参考值。偏差用未提前修约的数计算；相对偏差不等于相对不确定度，相近不自动证明相容。

## 讨论、改进与修订

- 每点回答“本次现象/差异是什么 → 哪个机制可能影响它 → 有何依据或待核实处”。没有观察记录的原因用可能性表述，不把所有误差因素逐一罗列。
- 总结用主要结果或认识，加能实施的对应改进；区分已实施的处理与后续建议，不编造实验体验。思考题按原题直接回答，操作题写动作与判据。
- 已誊写稿的确定错误、数据更正和参数更新必须处理，但不把可选排版升级为必改。局部修改先列前后对照与影响范围，并同步更新有关表格、结果和文字；无关部分不重新计算。

## 交付前核对

核对当前阶段、栏目与原题覆盖、数据和单位、计数/配对与物理模型、不确定度口径、修约及正文表图一致性。抄录稿留白适度、要点清楚；详细核算、估算说明和正文分开。文件交付另检查最终渲染；没有真实数据时只完成有依据的预习或空白骨架。
