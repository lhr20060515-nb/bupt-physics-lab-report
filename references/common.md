# 北邮物理实验报告的共用方法

本资料只服务于用户课表中需要正式报告的七项实验。课表决定范围；当次教师要求、讲义和原始记录决定具体任务。历史报告不能代替本学期要求。以下计算规范是本次归纳的通用科学方法，不能冒充北邮统一评分细则。

## 写作顺序

先列出本次要交的测量结果，再从结果倒推所需数据、图表和计算。每个结果应能追溯到“原始读数 → 换算或组合 → 模型或拟合 → 最终量及不确定度”。正文按 [报告本栏目与版式](report-form.md) 的五个栏目编排；原始记录、计算、不确定度和结果讨论作为第四栏的证据与内部小节。教师未要求时不额外堆摘要、目录和长篇背景。

先核对当次讲义与数据单，区分必做、选做、免做和题目编号。只在本次任务内应用用户明确的免做要求；历史报告中的扩展实验不自动加入。对不同方法分别列数据与处理，先比较再决定是否合并结果。报告内容足够支撑任务即可，不靠多画图、多做拟合增加篇幅。

原理只解释本次真正用到的测量关系和成立条件；装置图的符号必须与计算一致。步骤写清为何这样做，例如单向读数避免空程差、换向组合抑制附加电压、累计计时降低相对读数影响。不能把课本步骤写成自己已经实际完成的操作。

## 原始数据和图表

原始数据与加工数据分开，保留教师签认的原记录及修正痕迹。读数按仪器分辨力记录，不为了图像平滑或接近参考值修改数据。缺失项写“待提供”；可疑手写数字先列出疑点，不能悄悄猜值。只有明确标注“演示数据、不可用于提交”时才可生成教学示例。

每张数据表写量名、符号、单位、测量条件和重复次数。图注明横纵坐标单位、条件、数据点与拟合曲线的含义；趋势、斜率、截距或残差应服务于某个物理问题。最小二乘法不能自动替代课程指定的图解法或逐差法；需要时并列比较。不能把原始采样点之间的连线说成理论拟合。

## 不确定度

对于同一量的 n 次独立等精度重复测量，n≥2：

\[\bar x=\frac1n\sum x_i,\quad s=\sqrt{\frac{\sum(x_i-\bar x)^2}{n-1}},\quad u_A(\bar x)=\frac{s}{\sqrt n}.\]

区分单次测量的标准差 s 与平均值的标准不确定度。若讲义采用 t 系数或指定置信水平，要明确其约定；不要把标准不确定度与扩展不确定度混写。

B 类评定应注明仪器型号、量程、准确度说明和分布假设。已知矩形分布误差界限为 ±a 时，u_B=a/√3；若只考虑数字量化、分辨率为 q 且假设舍入均匀，则 u=q/√12。最小分度或厂家最大允许误差不能不经解释就直接当标准不确定度。旧报告中的“仪器误差取零”不能直接继承。

一般测量模型 y=f(x₁,…,xₙ)：

\[u_c^2(y)=\sum_i(\partial f/\partial x_i)^2u^2(x_i)+2\sum_{i<j}(\partial f/\partial x_i)(\partial f/\partial x_j)\operatorname{cov}(x_i,x_j).\]

只有在独立或相关性可忽略时才能省去协方差项。共用同一空载周期、同一波长、同一标尺的多行数据可能相关，不要因重复使用而把共同误差“平均掉”。拟合斜率的不确定度之外，还可能存在标定、读数和模型误差。

最终同时给出数值、单位、合成或扩展不确定度及其定义。通常不确定度保留一至两位有效数字，结果保留到同一小数位；若教师规定不同，从其规定。计算中保留保护位，最后再修约。

相对偏差 |y−y_ref|/|y_ref| 与相对标准不确定度 u_c(y)/|y| 是不同概念。参考值必须注明来源及其对应温度、波长或其他条件。偏差小不能证明不确定度预算完整。

## 分析写法

用“观察到的证据 → 物理机制 → 预计影响 → 可检验的改进”组织段落。例如说清转动惯量的偏心安装会怎样影响结果，不能只写“人为误差较大”。证据不足时写“可能”“需要进一步核验”，不能把猜测写成确定结论。结论回答测到了什么、多少、精度如何、在哪些条件下成立。总结只记录真实困难与解决过程。

## 提交前检查

- 每项任务都有数据、方法和结论；每个最终数字能回到原始记录。
- 单位、量纲、比值方向、周期计数和换向符号均与装置一致。
- 图、表、公式符号一致；不把 mm 当 m、mA 当 A、kGs 当 T。
- 不确定度约定、仪器依据、舍弃数据的理由和参考值来源均已说明。
- 思考题逐题作答，不复制历史报告中的个人经历和未经核验的判断。
- 五栏结构与用户报告本一致；原理/步骤在第三栏内分开，结果讨论在第四栏，问题与总结在第五栏，教师区域留空。
- 交付电子文件时检查公式正常渲染、图表单位与正文引用、跨页及留白；未经逐页查看不声称排版已验收。
- 未获得当次讲义或数据时，交付可填写模板与缺口清单，不交付貌似完成的实验结果。
