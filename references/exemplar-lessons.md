# 北邮范文与空白报告本的对照及取舍

本轮已直接查看 G1 电桥 PDF第2、5、8页，霍尔第2、6页，声速第2、4、7页，以及 G2 声速第35页。来源及去重关系见 [sources.md](sources.md)。样本可作为写法参考；文件名中的90/A和教师勾画均不能证明所有计算正确，不能代表七项实验均已有同题高分样本。

## 结构是否一致

G1 的电桥、霍尔、声速前半部分印有“实验目的”“实验仪器名称〔型号、主要参数〕”“实验原理和操作步骤”；声速处理页印有“实验数据处理与讨论”；霍尔末页印有“回答问题与实验总结”“任课教师指导意见”。这些与用户空白报告本的对应栏目相同。历史样本另有封面与实验要求/数据单，不能据其装订页数替用户重建未经确认的封面。

G2 声速也保留实验要求及原始数据单；原始单上有测量方法、条件、读数和签认区域。这支持保留完整证据链，而非仅产出漂亮的结论表。

## 具体借鉴与修正

| 范文观察 | 保留的写法 | 本 skill 中的处理 |
|---|---|---|
| 电桥：原理紧邻接线图；计算页分直接法与交换法，给代入、不确定度和结果 | 电路节点—平衡关系—读数—结果对应；比较方法时先分别算 | 按当前桥臂重新映射，保留共同标定相关性，避免因旧报告写得简洁就漏掉依据 |
| 电桥：某些灵敏度计算有红笔质疑 | 将批注当成需复核的线索 | 重新核对灵敏度定义、相对电阻变化和格数，不继承错误数值或把批注当标准答案 |
| 霍尔：解释载流子受力并画方向图；末页按问题编号回答 | 机制、方向、测量量相互对应；思考题答案有理由 | 原始四方向读数先映射再组合，不能把换向写成消除全部附加效应；仪器主要参数仍需本次补齐 |
| 声速：振幅、行波比较、李萨如方法分表，给位置差、平均量及声速代入 | 多方法分别处理、最后比较；表头写单位，展示一组换算 | 每次重新确认状态间隔是半波长还是整波长，频率与温度来自本次记录，不抄旧系数和数值 |
| 声速 G1 与 G2 均保留实验要求和原始数据单 | 从任务及原始数据追溯处理过程 | 先标本次必做/选做，保留原始单；历史题目及免做项不跨实验继承 |

等厚干涉采用北邮教师研究支持方法；转动惯量已有作者授权的 [扭摆成稿](../examples/02-torsion-report-90plus.pdf)；简谐振动的公开历史同题完整范文仍有缺口；静电场 JSON 只作线索，不算完整优秀范文。各实验仍按当次讲义确认装置和任务，历史样本仅供结构与表达参考。

## 综合标准

优先选能展示任务完成、公式含义、读数来源、计算过程、结果解释和实际限制的写法，不按篇幅、装饰或“高分”文件名筛选。取共同可靠做法，不拼接不同实验和不同装置的参数。当前教师规范及当次讲义/原始单决定任务；用户报告本决定当前默认结构；历史范文补充表达方式。
