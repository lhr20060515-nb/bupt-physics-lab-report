# 北邮物理实验报告本：栏目、内容与排版

## 依据与使用时机

栏目依据北邮物理实验报告本的空白页核对；其中有学校物理实验报告页眉及物理实验中心印制信息。公开版提供原创栏目整理和可填模板。各学年、学院、教师的实际要求可能不同，使用时以本人当次报告本为准。

公开版不分发原件扫描图。需要复原版式、确认填写区域或解决栏目歧义时，请使用者提供本人当次空白报告本；本页的栏目映射在没有扫描图时仍可直接使用。不把扫描背景当成电子文档固定背景。

## 栏目与内容映射

| 原件栏目 | 正文应覆盖 | 与七分流的衔接 |
|---|---|---|
| 实验目的 | 学习的方法、需要测量或验证的量；与当次任务一致 | 不照抄历史范文多出的任务，不预写成功结论 |
| 实验仪器名称〔型号、主要参数〕 | 实际仪器名称及已知型号、量程、分辨力、准确度或关键参数 | 按所选分流确定影响公式和不确定度的参数；未知型号标待补，不猜测 |
| 实验原理和操作步骤〔基本物理思想、设计原理、主要公式及其意义、电路图或光路图等；操作步骤〕 | 内部分“实验原理”和“操作步骤”；解释测量链、模型条件、公式符号与单位，配本次所需装置/接线/光路图；步骤说明调节、记录与误差控制 | 保留分流的装置判断；预习写计划，实验后仅依据记录写实际操作 |
| 实验数据处理与讨论〔实验数据计算、不确定度公式推导与计算、结果表示与讨论等〕 | 按当次处理题顺序组织：数据依据、派生量、代表性代入、图表或拟合、要求的不确定度、最终结果、讨论 | 每种方法独立处理再比较；不确定度推导或计算依本次必做/选做要求，不机械补做历史选题 |
| 回答问题与实验总结 | 按当次原题编号回答，再写完成任务、主要认识和有记录的操作问题及改进 | 分流中的“理解检查”不是教师原题；找不到原题只给准备要点 |
| 任课教师指导意见 | 保留空白 | 不生成评价、成绩、签名或批改痕迹 |

原始数据单单独保留，维持原表、签认、修正和页码关系。第四栏可给出必要摘录及加工表，但注明来源并区分实测列与计算列，避免手工转录后失去追溯。用户没交数据时可完成有依据的预习或空白表，不能形成实测结论。

## 第四、第五栏的写作质量

第四栏的每项任务形成“要求 → 数据 → 公式/方法 → 代入或图表 → 结果 → 解释”的闭环。至少在首次使用某种计算时给出一组带单位的代入，其余重复计算用表格。要求逐差时列配对及间隔数；拟合时交代自变量、因变量、斜率单位和参数对应，不用相关系数代替物理分析。

原始记录、处理表与图形的关系、配对映射及具体列式按 [数据关系与计算呈现](data-presentation.md) 展示；每个关键结果有公式、带单位代入和数值结果，不只列公式或只报数字。

“结果表示与讨论”属于第四栏。先按约定写结果和不确定度，再结合本次数据讨论重复性、偏差、残差、附加效应或几何边界等；只写证据支持的误差方向。参考值需要条件和来源；没有适用参考值时不强算百分误差。

第五栏逐题作答，说明适用条件和理由；“实验总结”简洁归纳真实结果与认识，不再重复整篇误差预算，不编造合作过程、操作经历或教师反馈。引用的方法可就近注明来源；不强加论文式参考文献章。

## 排版与交付方式

- **报告本抄录稿**：按五栏及内部小标题提供可抄写内容；根据用户提供的实际空白区域控制文字和图表密度。续页可以增加，不承诺恰好填满五页。不使用额外摘要、长目录、背景综述或自创封面替代本式结构。
- **填写已有 Word 模板**：在副本上编辑，保留已有栏目、栏线、页眉页脚、教师区及指定字体。不要用连续空格对齐字段。原件没有给出精确字体字号和页边距，不把其他通用北邮 skill 的数值当官方规范。
- **重新生成电子报告**：默认以五栏为骨架；A4、清楚的中文字体、黑色正文、可辨认的公式和图表是可调整的排版选择。页眉页脚是否复刻、横线是否保留听从用户要求；不得把正文逐行强塞进扫描背景。无依据不新增封面字段或水印。
- **表格**：列头给量、符号与单位，原始值与加工值分清；需要跨页时重复表头，避免字号过小和宽表裁切。
- **图和公式**：接线/光路/装置与当前模型一致；坐标、单位、图例和测量条件可读；图表编号与正文对应。公式须在最终 DOCX/PDF 正常显示，符号不丢失，不留未渲染 LaTeX。图注跟随图，标题不孤立在页末。
- **验收**：先核对题目覆盖、数值和符号，再按交付格式编译或渲染，逐页检查裁切、溢出、跨页、字体、公式和教师留白。若不能渲染，说明未完成视觉核验；只审阅文字时不要求无意义的导出。

七份可填模板是本次据扫描件整理的编辑骨架，含填写提示，不是已完成报告。生成提交稿时清除模板提示、未使用的候选方法和多余占位，真实缺口在交付说明中明确；需要带占位的草稿时保留。
