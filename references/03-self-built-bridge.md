# 自搭电桥研究与写作分流

## 证据与适用范围

有两份北邮电桥报告全文可交叉比较；均为历史单臂电桥资料，是否要求交换法及灵敏度实验须以当次任务为准。

来源编号：G1, G3, P4。详见 [来源与核验记录](sources.md)。本页明确标为候选模型的内容是物理推导与写作建议，不是已取得的本学期讲义要求。

## 模型选择与核心原理


先确认本次是直流惠斯登单臂电桥，核对接线和桥臂编号。不是单臂电桥时，不套此分流公式，先按讲义改写。

本资料统一定义：电源接上节点 P 与下节点 Q；左支路 P—R_A—L—R_B—Q；右支路 P—R_C—R—Rₓ—Q；检流计接 L、R。平衡时 V_L=V_R，R_B/(R_A+R_B)=Rₓ/(R_C+Rₓ)，故 Rₓ=(R_B/R_A)R_C。学生讲义若编号不同，应从节点关系重新对应，不能照抄比值。

若 R_C=R_s 为可调标准电阻，在固定比率臂不变的条件下，将 R_s 与 Rₓ 所在右桥臂位置互换，再调得 R_s′，两次平衡给出 Rₓ=√(R_sR_s′)。交换的是指定标准臂和待测臂，若连比率臂一起交换，这个关系未必适用。交换法可减弱比率臂误差，但不是消除所有误差。

如要求测灵敏度，按讲义定义记录 S=Δn/(ΔR/R) 或输出电压对相对电阻变化的响应，写清 Δn 的格数、ΔR 对应哪一桥臂和量纲；不同灵敏度定义不要混写。


## 需要保留的数据

电源电压、检流计量程或保护设置、四桥臂对应图。每次记录 R_A、R_B、平衡 R_s、交换后的 R_s′、电阻箱型号与准确度；灵敏度实验另记 ΔR、偏转方向和格数 Δn。

## 处理顺序与必备图表

按实际节点推导平衡公式；从每组平衡读数计算 Rₓ；若做交换法，用成对 R_s、R_s′ 计算几何平均并比较。用实际数据说明电桥接近零位时的调整过程。不得把箱式电桥操作当作已经完成的自搭接线。

## 不确定度

直接法在独立条件下：(u(Rₓ)/Rₓ)²=(u(R_A)/R_A)²+(u(R_B)/R_B)²+(u(R_C)/R_C)²，并评估平衡判别、接触与电源条件。交换法独立时 u(Rₓ)/Rₓ=0.5√[(u(R_s)/R_s)²+(u(R_s′)/R_s′)²]；若同一电阻箱两次读数共享标定误差，要保留相关项，不能误称标定误差完全抵消。

## 常见错误

桥臂比值颠倒；没有接线图；把算术平均当交换法结果；电阻箱误差公式里的读数、量程、残余电阻项不清；把灵敏度高等同于无系统误差；未给检流计保护措施。

## 讨论写法

比较直接法与交换法的不确定度，解释改善来自何处及仍保留哪些误差。通过实际灵敏度数据分析比率臂、供电和检流计条件的影响；不要笼统断言电压越高越好，应结合允许功耗和发热。

## 思考题准备

以下是理解检查，不冒充本次教师原题：平衡时为什么可以不依赖检流计电阻？交换法在何种接线下成立？为什么电桥灵敏度与最终准确度不是一回事？低值电阻为什么容易受导线和接触影响？

## 按报告本五栏填写本实验

栏目与版式以 [用户报告本](report-form.md) 为准；下面是本分流的内容映射，是否必做仍核对当次讲义与数据单。

| 栏目 | 本分流写作重点 |
|---|---|
| 实验目的 | 掌握自搭惠斯登电桥平衡与测阻；交换法、灵敏度或箱式电桥比较依当次任务选择。 |
| 实验仪器名称 | 桥臂/电阻箱型号与准确度、检流计及保护设置、电源；不能用范文器件型号代替实物。 |
| 实验原理和操作步骤 | 先画节点清楚的实际电路，再按电位关系推出平衡式；交代接线、限流保护、粗调细调与换接次序。 |
| 实验数据处理与讨论 | 保留桥臂与平衡读数；直接法和交换法分别列表、带单位代入及评定不确定度后比较。灵敏度若要求，另列 ΔR、Δn 和定义。 |
| 回答问题与实验总结 | 解释交换法改善的来源与局限、平衡判别和接触影响；思考题答案与本次桥臂定义一致。 |

## 交付门槛

先核对讲义任务和装置，再核对原始记录及单位；有真实数据才作定量结论。只缺不影响推导的信息时可继续分析，缺关键装置或计数约定时先交模板和待核验项。报告格式与通用质量检查读 [common.md](common.md)；对应可填模板见 [报告模板](../assets/03-self-built-bridge.md)。
