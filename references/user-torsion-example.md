# 用户扭摆报告：生成稿、采纳稿与规则取舍

来源U4：[作者授权公开的五页报告](../examples/02-torsion-report-90plus.pdf)，作者说明成绩90+。逐页对照成稿，并经作者授权读取对应扭摆聊天中的预习、数据处理、誊写反馈和附件更正。只公开写法归纳，不公开聊天全文。该样本支持用户的表达偏好，不保证每个旧数值或参数都正确。

| 对照点 | 生成与反馈中发现的问题 | 成稿采用的写法／本skill的处理 |
|---|---|---|
| 目的、仪器 | 展开过多会挤占预习留白 | 目的两点、仪器紧凑列举；未知参数待补 |
| 原理 | 只有公式列表不利于理解，整段泛讲又抓不住测量设计 | 从回复力矩、方程、周期进入标定与附件扣除，每步用短句解释物理量 |
| 操作 | 把每个动作都细碎拆开或省成“按要求操作”均不合适 | 按装样状态顺序分点，每点写动作、测什么和必要判据 |
| 数据计算 | 早稿将周期不确定度夹在结果计算前，栏目边界不清 | 成稿先列周期表、标定和惯量计算；当前明确要求三小项分开，优先采用最新要求 |
| 推导详略 | 完整微分、每个重复算式与多次限定说明过长 | 正文保留关键推导、代入和结果；同式结果列表，详细核算放末尾供核对 |
| 结果表 | 助手在誊写后把可选±写法说成必须返工 | 模板和已约定安排优先；正文完整结果与中心值汇总表可以并存；确有错误才定点改 |
| 思考题、总结 | 长解释偏离题意、总结重复误差预算 | 两题各自给概念/方法与关键式；总结用测量链、处理注意点和可实施改进收束 |
| 后续更正 | 附件组别改变会连带惯量、偏差和结论 | 给前后对照及影响范围，同步必要结果，不重写无关段落 |

## 借鉴边界

- 原件第3—4页保留早期附件参考值；写作聊天后续确认了另一组器材参数。原件作为已提交写法样本原样保存，不将旧参数或旧“偏差均小于0.4%”结论设为新报告默认值。
- 第4页汇总表的时间标题与实际NT量值需区分；借鉴表格布局时明确写NT/s或填入单周期T/s，不能照抄含糊表头。
- 成稿中的仪器不确定度估值与课堂简化必须核对当前依据；高分不替代算法、单位和条件复核。原件正文没有的装置图、固定页数和缺失参数不凭空补成通用规定。
- 当前报告本第三栏明确提示基本物理思想、设计原理、公式意义与图；即便旧成稿未逐个标成小标题，新写预习仍应按当前模板分别覆盖。

由此删去的默认行为：把通用理论搬入正文、每种方法从结果到全部误差预算交错写、各分流重复栏目和验收口号、自拟思考题替代原题、把可选写法当成誊写后必改项。保留公式、带单位代入、原始—处理关系及必要模型条件。
